## 🚀 Chạy ở máy của bạn

```bash
# Windows: chạy game.bat (mở http://localhost:8000)
# Máy khác:
python3 -m http.server 8000   # mở http://localhost:8000
```

Chơi với máy / cùng máy thì không cần gì thêm. Chơi online với bạn ở xa cần máy chủ phòng — thư mục `server/` deploy lên Cloudflare Workers (miễn phí):

```bash
cd server && npx wrangler deploy
```

## 🗂️ Cấu trúc

```
index.html            Trang chủ: 97 game, tìm kiếm, lọc theo nhóm
<game>/               Mỗi game một thư mục (luật + bot + online riêng)
sanh/                 Sảnh chung: tìm phòng, chat thế giới
shop/                 Cửa hàng + Rương Gacha
xephang/ · hoso/      Bảng xếp hạng · Hồ sơ (trang riêng)
luat/                 Wiki tổng hợp: game, luật, vật phẩm, thành tựu
shared/               UI + mạng dùng chung (topbar, footer, ví xu, huy hiệu…)
server/               Cloudflare Worker gumballz-rooms (Durable Objects)
tools/                Sinh wiki, hướng dẫn, ảnh OG, kiểm tra
game.bat              Chạy web ở máy Windows (localhost:8000)
```

## 🛠️ Công nghệ

- **Web tĩnh** HTML/CSS/JS thuần, không cần build — host trên Vercel.
- **Cloudflare Workers + Durable Objects** (`Room`, `Inbox`, `Users`, `Lobby`): phòng chơi, tài khoản, bảng xếp hạng, chat.
- **Rive**: animation tile game, rương Gacha, banner đăng nhập.
- **PeerJS / MQTT** dự phòng khi không có máy chủ riêng.

Nhật ký thay đổi đầy đủ: xem [CHANGELOG.md](CHANGELOG.md).
